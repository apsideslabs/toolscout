Method

How a tool gets in

5531 tools across 18 jobs. Every one of them passed the same five tests, and the tests run again every month.

  1. Not archived. A repository the maintainer has closed is excluded, however popular it is.
  2. Pushed within twelve months. A tool that has not moved in a year is not maintained, whatever the README says.
  3. Carries a licence. No licence means no legal right to use it. Those entries are dropped.
  4. At least 400 stars, for libraries. A floor for community validation, not a quality score.
  5. AI and editing tools come from a public directory. The 1,657 AI and media entries are harvested from aitoolindex.org, which checks each vendor page and stamps a date. They are labelled Platform, carry a pricing model, and link straight to the vendor.
  6. Hosted platforms are curated, not machine-checked. Stripe, Vercel and Clerk have no repository to read, so they are listed by hand and reviewed on the check date. Their rows say Platform, and the licence reads Proprietary.
  7. Outliers cross-checked against forks. Above 100,000 stars the fork count is checked too, because star farms accumulate stars without contributors. Real projects at that scale are forked at 10-20% of their star count.
  8. Metadata read at build time. Stars, licence, language and last push come from the GitHub API, not from a directory listing.

What this index will not claim

A listing is not an endorsement. Admission means a project is public, active and licensed — not that it is secure, well-designed, or right for your problem. Read the open issues before you install anything.
